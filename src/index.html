ENGINEERING NOTE / 01

Internal boundaries ≠ microservices.

Ghost's API, frontend renderer, and services are distinct layers inside one Node.js runtime. Extra Ghost 6 services are optional and separate from this core map.

ENGINEERING NOTE / 02

Never mistake a model for telemetry.

Our trace estimates are deterministic illustrative values. They are not actual Ghost performance benchmarks, production metrics, or live API results.

    BOUNDARY TO WATCH

    HTTP vs. in-process calls

    Ghost's Admin and Content APIs expose HTTP boundaries. The public theme can call internal server capabilities without making an external Content API request.

    OPERATIONAL TRADE-OFF

    Scale the edge before the core.

    Ghost recommends CDN and caching for high-volume sites. This lab models an edge cache hit as a path bypass, but makes no capacity claims.
